# Project Planning Phase

## Project Objective

To develop an AI-powered application that creates personalized comics using text and image generation models.

## Project Activities

1. Model Selection – Select Gemini Flash, Gemini Pro, and Stable Diffusion.
2. Core Development – Develop story, image, layout, and PDF generation functions.
3. Backend Development – Create FastAPI routes and integrate AI models.
4. Frontend Development – Design the input form and comic preview pages.
5. Deployment – Configure the environment and test the application.

## Tools Used

* Python
* FastAPI
* Google Gemini
* Stable Diffusion
* HTML and CSS
* GitHub

## Expected Result

A functional web application that generates and exports personalized comics.
