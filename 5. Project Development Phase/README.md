# Project Development Phase

The development phase focuses on implementing the main features of ComicCraft.

## 1. Story Generation

Gemini Flash generates a structured five-panel comic outline.

## 2. Narration Generation

Gemini Pro creates narration and character dialogues.

## 3. Image Generation

Stable Diffusion generates illustrations for each comic panel.

## 4. Layout Building

The layout builder combines images, titles, and story text.

## 5. PDF Generation

FPDF creates a downloadable PDF containing comic panels and narration.

## 6. Backend Integration

FastAPI connects all modules and processes user requests.

## 7. Frontend Development

Jinja2 templates display the input form, comic preview, and export-success page.
