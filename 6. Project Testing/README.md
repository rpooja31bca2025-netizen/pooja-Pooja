# Project Testing

## Testing Objective

To verify that all the features of ComicCraft work correctly.

## Test Cases

1. Homepage – Check whether the input form appears.
2. User Input – Check whether user details are accepted.
3. Story Generation – Check whether a five-panel outline is generated.
4. Narration – Check whether stories and dialogues are generated.
5. Image Generation – Check whether comic illustrations are created.
6. Comic Preview – Check whether images and text are displayed.
7. PDF Export – Check whether the comic is exported as a PDF.
8. API Testing – Check whether API endpoints respond correctly.

## Testing Methods

* Unit Testing
* Integration Testing
* Functional Testing
* User Interface Testing

## Expected Result

All major features should work correctly, and errors should be handled properly.
