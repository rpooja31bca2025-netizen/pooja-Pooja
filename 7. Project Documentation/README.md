# Project Documentation

## Project Name

ComicCraft – AI Comic Story Creator Using Gemini Models

## Project Description

ComicCraft is a web-based AI application that transforms user-provided story ideas into illustrated comic books.

## Technologies Used

* Python – Application development
* FastAPI – Backend processing
* Gemini Flash – Comic outline generation
* Gemini Pro – Story and dialogue generation
* Stable Diffusion – Image generation
* HTML and CSS – User interface
* Jinja2 – Dynamic templates
* FPDF – PDF generation

## Working Procedure

1. Open the application.
2. Enter the story prompt.
3. Provide the character name.
4. Select the setting, tone, and art style.
5. Generate the comic.
6. View the comic preview.
7. Download the comic as a PDF.
