# Project Demonstration

## Demonstration Objective

To demonstrate how ComicCraft converts a user's story idea into a complete comic.

## Demonstration Steps

1. Start the FastAPI application.
2. Open the homepage in a web browser.
3. Enter a sample story prompt.
4. Enter the main character's name.
5. Select the setting, tone, and art style.
6. Click the Generate button.
7. Display the generated five-panel comic.
8. Show the illustrations, narration, and dialogues.
9. Click the PDF download button.
10. Display the export-success page.

## Expected Output

The application generates a five-panel comic with AI-created illustrations, narration, and dialogues. Users can view the comic and download it as a PDF.

## Conclusion

ComicCraft demonstrates how artificial intelligence can simplify comic creation by combining automated storytelling, image generation, and PDF export.
